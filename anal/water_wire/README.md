# Water-wire analysis

This directory contains the existing water-network analysis tools:

```text
calc_water_prox.py
calc_water_wire.py
```

The repository also contains `smoke.sh` and reference/test outputs for the CHARMM22, Amber ff14SB, and Amber ff19SB workflows.

`calc_water_prox.py` and `calc_water_wire.py` remain unchanged by this analysis-tool reorganization. Their script-level arguments and existing smoke/reference data should be treated as the authoritative usage source.
